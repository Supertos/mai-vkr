# Разработка программной среды дистрибуции и исполнения модулей в среде UEFI

## Актуальность
С развитием UEFI разработка ПО для среды без отдельной операционной системы становится все более доступной.
Существует проблема множества дополнительных шагов: необходимости загрузки в ОС, отдельной компиляции в PE формат, используя библиотеки поддержки UEFI-ABI, и запись на накопитель.

## Цель
Разработать программную среду дистрибуции и исполнения в среде UEFI, предоставляющее конечному пользователю возможность выбора и компиляции (через сторонний компилятор) исходного программного кода; запуска производимых компилятором ELF программ.


## Задачи
1. Разработать программный интерфейс парсинга1 и статической линковки2  ELF файлов;
2. Разработать расширение для динамической линковки3;
3. Разработать минималистичную стандартной библиотеку для доступа к функциям UEFI;
4. Разработать командный интерфейс для конечного пользователя;
5. Произвести интеграцию со сторонним компилятором.


## Предмет и объект исследования
- Объект исследования: Предзагрузочная среда UEFI;
- Предмет исследования: UEFI API, слои совместимости, процесс загрузки исполняемого машинного кода.

## Стек технологий
1. Язык С23;
2. Библиотека GNU-UEFI2.

## Практическая значимость
Посредством использования такого комплекса устраняется необходимость загружаться в ОС – компиляция и загрузка происходят в среде UEFI.
Создается возможность быстрой и удобной доставки исходного кода на целевую ЭВМ с других ЭВМ.
Предоставление стандартной библиотеки устраняет необходимость использовать библиотеки-прослойки – упрощается процесс разработки под UEFI.


## Ожидаемые результаты
Ожидаемым результатом является программная среда дистрибуции и исполнения, состоящая из:
-Стандартной библиотеки, ее исходного кода и документации к ней;
-Исполняемого файла PE (и его исходного кода), предоставляющего интерфейс для загрузки файлов с исходным кодом, передачи их компилятору и последующему запуску результата работы компилятора;
-Документации по подключению внешнего компилятора.
