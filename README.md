# Разработка программной среды дистрибуции и исполнения Си-модулей в среде UEFI

## Актуальность
С развитием UEFI разработка ПО для среды без отдельной операционной системы становится все более доступной.
Существует проблема множества дополнительных шагов: необходимости загрузки в ОС, отдельной компиляции в PE формат, используя библиотеки поддержки UEFI-ABI, и запись на накопитель.

## Цель
Разработать EFI приложение для среды UEFI, предоставляющее конечному пользователю возможность, выбора и компиляции (через сторонний компилятор) исходных файлов и запуска производимых компилятором ELF программ.

## Задачи
1. Разработать программный интерфейс парсинга и статической линковки ELF файлов;
2. Расширение программного интерфейса для динамической линковки;
3. Разработка минималистичной стандартной библиотеки для языка семейства Си;
4. Разработка командного интерфейса для конечного пользователя и интеграция со сторонним компилятором.

## Предмет и объект исследования
- Объект исследования: Предзагрузочная среда UEFI;
- Предмет исследования: UEFI API, слои совместимости, процесс загрузки исполняемого машинного кода.

## Стек технологий
1. Язык С23;
2. Библиотека GNU-UEFI2.

## Практическая значимость
Интерфейс командной строки в среде UEFI с возможностью компиляции, и предоставление им стандартной библиотеки, подобной тем, что используется в операционных системах, устранило бы необходимость загружаться в ОС.
Создается возможность, использовать hot-plug переносимых носителей с программным кодом, и компилировать их на месте.
Упрощается процесс разработки под UEFI благодаря отсутствию необходимости использовать отдельную библиотеку-прослойку.

## Ожидаемые результаты
Стандартная библиотека для языка семейства Си, ее исходный код и документация к ней;
PE исполняемый файл и его исходный код для просмотра и передачи компилятору исполняемого файла, а также для запуска результата его работы;
Документация по подключению внешнего компилятора
